# Shenanigan's Snug website (preview)

Static preview site for Shenanigan's Snug Irish Pub & Grill, Cave Creek, AZ.

- `index.html` holds every page (Home, Menu, Order online, Events, Reservations, Private parties, Our story, Gallery, Visit, Staff dashboard preview).
- `img/` holds the logo and photos (photos are from Mountain View Pub).
- No build step. On Vercel choose Framework Preset "Other" and leave the build command empty.

## Not live yet
Orders, bookings, party requests and messages are not sent anywhere, and staff dashboard changes reset on reload.
Hours, events, address and phone are examples. The real backend (Clerk staff login, database, Stripe) is the next phase.
